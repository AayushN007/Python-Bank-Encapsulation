# Python Bank Encapsulation

## 📘 Overview

This repository demonstrates the concept of **Encapsulation** in Python using a simple **Bank Management** example. The program stores account information as private attributes and provides controlled access through getter and setter methods.

Encapsulation is one of the four fundamental principles of Object-Oriented Programming (OOP). It helps protect data by restricting direct access and allowing modifications only through predefined methods.

---

## 📂 Program Features

* Create a bank account object using a constructor.
* Store account details as private attributes.
* Update all account details using a common setter method.
* Retrieve all account details using a common getter method.
* Modify individual attributes using dedicated setter methods.
* Access individual attributes using dedicated getter methods.
* Demonstrate secure data handling through encapsulation.
